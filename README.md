## Smart Delivery Operations Analytics System | MySQL

A SQL-based food delivery analytics project using **MySQL** to analyze operations, revenue, customers, and delivery partners.

### 🔹 Key Highlights

* 7 interconnected tables with **29,300+ records**
* Data import, cleaning & validation
* **40+ SQL queries** for business analysis
* Used **Joins, Subqueries, CTEs, Window Functions & Aggregations**
* Analyzed:

  * 🚚 Delivery performance
  * ❌ Order cancellations
  * 💰 Revenue & payment trends
  * 👥 Customer retention & churn
  * 🛵 Delivery partner performance

### 🛠️ Tools

**MySQL 8.0 | MySQL Workbench | SQL | CSV**

### 📊 Outcome

Generated actionable insights and recommendations to improve **delivery efficiency, customer satisfaction, retention, and revenue**.
